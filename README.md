# Green Futures

Green Futures is an interactive student guide to ten environmental science careers. It was built as a clean, simple high-school research project and can be hosted directly with GitHub Pages.

## Features

- Search and filter ten environmental careers
- Detailed profiles covering education, programs, salary, outlook, typical day, challenges, and advantages
- Compare up to three careers side by side
- One-question career matcher
- Links to U.S. Bureau of Labor Statistics sources
- Responsive layout for phones and computers

## Run locally

Open `index.html` in a browser. No build tools or packages are required.

For a local web server, run:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Open the repository settings on GitHub.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the main branch and the `/ (root)` folder.

## Research note

Salary and outlook numbers are U.S. estimates based mainly on the U.S. Bureau of Labor Statistics Occupational Outlook Handbook. Starting salaries are approximate because they vary by location, employer, and experience. Quotes are labeled composite field perspectives and are not presented as original interviews.
